# **App Name**: EveCount.com - AI Venture Studio

## Core Features:

- Portfolio Showcase: Display the ventures created, including name, sector, and current status.
- Project Cards: Visually appealing cards to represent each venture in the portfolio, replacing a simple list.
- Venture Dashboard: A secure admin panel to view the status and health of all ventures.
- Lead Intake Form: A form for potential partners to pitch their vision.
- AI Gatekeeper for Foundry Sessions: Connect new leads from the intake form with OpenHours.ai to schedule a 'Foundry Session'. An AI tool decides when and whether a new lead needs to be pushed to the sales team.

## Style Guidelines:

- Primary color: Brushed steel (#B0B0B0) to convey a sense of industrial minimalism.
- Background color: Dark charcoal (#333333) to establish a high-end, workshop-like feel. A dark scheme is most appropriate, matching the "Industrial Minimalism" requested.
- Accent color: White (#FFFFFF) to create strong contrast for key elements, following the black and white color scheme request.
- Body and headline font: 'Inter' (sans-serif) for a modern, machined look suitable for both headlines and body text.
- Use a grid-based layout for the portfolio, highlighting the 'Project Cards'.
- Use minimalist icons representing each sector.
- Subtle transition animations between pages.
